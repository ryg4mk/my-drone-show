# マイドローンショー

ブラウザで画像をドローンショー風の光点に変換する静的Webアプリです。PNG・JPG / JPEG・GIFを最大3素材まで組み合わせられます。画像解析、GIFデコード、ショーの描画はユーザーの端末内で行い、選択した画像をサーバーへアップロードしません。ログインは不要です。

公開URL: https://ryg4mk.github.io/my-drone-show/

## 使い方

1. 初期サンプル3素材で試すか、画像を1～3個まとめて選びます。
2. 必要なら静止画像の表示範囲を四角で指定し、機数を選びます。
3. 夜空またはARを選んで「スタート」を押します。
4. 静止中のタップで次の素材へ進みます。最後の素材でタップすると終了演出に入ります。

ARはカメラ利用に対応したHTTPSブラウザとカメラ許可が必要です。カメラ映像は端末上の `video` 要素に表示し、サーバーへ送信しません。

## 構成

リポジトリ直下の `index.html` をGitHub Pagesの `main` ブランチ `/(root)` から配信します。ビルドやサーバー側処理は不要です。画像解析は `sampler.mjs` / `photo.mjs` / `worker.js`、GIF処理は `gif.mjs`、描画は `renderer.mjs`、再生計画は `show-plan.mjs`、操作とカメラは `app.js` に分かれています。サンプル素材とWorkerは相対URLで読み込むため、`/my-drone-show/` のサブパスで動作します。

アクセスカウンターのみ共有カウンターAPIへアクセスします。通信できない場合はカウンターを非表示にし、ショー本体は引き続き動作します。画像・ファイル名・個人情報はカウンターAPIへ送信しません。

このリポジトリは既存のchatgpt.site版から独立したコピーです。
